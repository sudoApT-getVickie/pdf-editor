
# Project Blueprint

## Overview

A web-based PDF editor with a 'Digital Brutalism' aesthetic. The application allows users to upload and view PDF files.

## Styling and Design

*   **Aesthetic:** Digital Brutalism
*   **Background Color:** Stark black (#0A0A0A)
*   **Borders:** Harsh 1px solid gold (#FFD700)
*   **Typography:** Off-white monospace
*   **Corners:** Sharp 0px border-radius
*   **Hover States:** High-contrast, with a gold background and black text.

## Features

*   **Layout:**
    *   Top navigation bar
    *   Left sidebar for uploaded file thumbnails
    *   Large central canvas for the active PDF page preview
*   **File Handling:**
    *   Users can upload PDF files.
    *   Thumbnails of uploaded files are displayed in the left sidebar.
    *   The active PDF page is displayed in the central canvas.
